# Дмитрий — SFA-P46-UNITTEST-ADAPTER R1

Проект: Sales Manager First. Результат: новый программный адаптер результатов `unittest` к точному формату записей F1-27.

Это разработка законченного компонента P46, а не повторная разработка F1-27 и не учебное тестовое. Автор исходного F1-27 сохраняет своё задание; его реализация пока не принята и в этом комплекте не используется. Замороженный интерфейс достаточен для разработки адаптера. Рабочее подключение после приёмки потребует принятой точной версии F1-27 и отдельного интегратора.

1. Прочитайте `CONTRACT_RU.md`, `reference/F127_CONTRACT_RU.md` и `INTEGRATION_RU.md`.
2. Реализуйте только `source/audit_release/unittest_evidence.py`; добавьте собственные тесты `tests/test_candidate_*.py` и документацию.
3. Выполните проверки из `TESTING_RU.md`. Публичный набор дополняйте, а не меняйте.
4. Сдайте один ZIP по `RETURN_RU.md`.

Контракт основан на оригинальном P46/W19 и прямом требовании F1-27: входные записи должны быть нормализованы по каждому случаю отдельным адаптером, а агрегированный вывод раннера для этого не подходит. Адаптер не принимает решение о выпуске, не устанавливает доверие к пользователю и не авторизует внешнее действие.
