# Проверки

Из корня пакета Python 3.12:

```bash
python -B CHECK_PACKAGE.py
python -B RUN_PUBLIC_TESTS.py
python -B RUN_CANDIDATE_TESTS.py
```

Создайте собственные тесты `tests/test_candidate_*.py`. Обязательный `RUN_CANDIDATE_TESTS.py` требует хотя бы один реально выполненный собственный тест и отвергает пропуски и ожидаемые ошибки; прямой запуск `unittest discover` не заменяет эту обязательную проверку. Первый запуск проверяет защищённые условия и примеры, а не реализацию. До реализации публичный набор намеренно завершается ненулевым кодом `IMPLEMENTATION_REQUIRED`. Это не успешная приёмка и не дефект поставленного задания. После реализации все публичные и собственные сценарии обязательны, без пропусков, ожидаемых ошибок и нулевого прогона внешнего набора.

Внутренние искусственные экземпляры `TestCase` обязаны содержать намеренные провалы, ошибки и пропуски для проверки записи исходов. Ожидаемая ошибка внутри специально созданного внутреннего набора не является провалом внешнего теста; внешний тест обязан явно проверить её корректную запись. Собственные тесты на неподдерживаемые возможности `unittest` должны проверять точный код `INVALID_EXECUTION`, а не скрывать такие события.
